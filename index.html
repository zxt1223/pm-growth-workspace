UI 设计 Prompt（完整）

明亮风 SaaS 中后台设计语言

背景：浅紫蓝渐变 #EEF1FF→#F5F7FF→#FAFAFE，白色 24px 大圆角悬浮面板 + 柔和多重阴影。 主色：#4F6BFF（hover #3D57E6），浅色面 #E8EDFF。 文字：#1A2233 / #6B7280 / #9CA3AF。状态：success #16A34A、danger #DC2626、warn #F59E0B、info #2563EB。 侧边栏：240px 白底，用户卡 + 分组菜单，选中态为整行 pill 浅蓝背景 + 主色实心线性 icon（20px / 1.75px stroke）。 顶部条：大标题 + 副标题、居中搜索框、icon 按钮（消息/铃铛小红点）+ 头像、Month ▾ 下拉 + 蓝色 Export 主按钮。 KPI 卡：4 列网格，大 tabular 数字 + 涨跌 chip（绿↑/红↓）+ 右上迷你 sparkline + View Report →。 图表：圆角柱状图（Profit/Loss 双系列）、环形图（中心指标 + 百分比标注）、状态环（外环刻度 + 双小指标）；纯 SVG，无图表库。 表格：白卡 + 图标工具栏（Search/Columns/Density/Filter/Export）+ 主按钮；选中条高亮提示；双行单元格（32px 头像 + 姓名 + 邮箱）；状态胶囊（Member/Signed Up/Verified/Replication Needed/Code Suspended）；行 hover 浅蓝 + 左侧 3px 主色边条；底部分页。 微交互：hover 200ms ease-out、tabular-nums 防抖、浅灰骨架占位、空状态插画。 交付：单页、图表用纯 SVG、4 场景（Dashboard/Events/Locations/Staff）、:root 集中 CSS 变量、预留暗色 hook。 —— 以上为精简版，完整 12 节 + 一句话版见 ui-design-prompt.md ↗
